Treatment Exposure Definition Report

Step 4 — Synthetic RWE Diabetes Treatment Study

Study population N = 69

Treatment Definition Rules

Group A (Metformin users): Index diabetes medication class = Metformin.

Group B (Other diabetes medication users): Index medication is any other glucose-lowering agent (insulin, GLP-1, sulfonylurea, etc.).

Multiple medication users: Received both metformin and a non-metformin diabetes medication during follow-up (descriptive category for exposure complexity).

Index treatment date: First diabetes medication exposure date after T2DM diagnosis (aligned with Step 2 index_date).

Medication Classification Logic

  • Metformin: pattern (?i)metformin
  • Insulin: pattern (?i)insulin
  • GLP-1 receptor agonist: pattern (?i)liraglutide|semaglutide|exenatide|dulaglutide
  • SGLT2 inhibitor: pattern (?i)empagliflozin|dapagliflozin|canagliflozin
  • DPP-4 inhibitor: pattern (?i)sitagliptin|saxagliptin|linagliptin
  • Sulfonylurea: pattern (?i)glipizide|glyburide|glimepiride|glipizide
  • Thiazolidinedione: pattern (?i)pioglitazone|rosiglitazone
  • Other antidiabetic: pattern (?i)repaglinide|nateglinide

Classification is applied to the DESCRIPTION field in medications.csv using case-insensitive regular expression matching.

Exposure Period Definition

  • Baseline period: 365 days before treatment initiation (baseline_start_date to treatment_start_date)
  • Follow-up period: From treatment_start_date through followup_end_date (minimum 730 days administratively, censored at death or last observed medication)

Exposure Limitations

  • Synthea synthetic data contains limited antidiabetic drug classes (primarily metformin and insulin).
  • Medication end dates (STOP) may be missing for ongoing prescriptions, affecting discontinuation detection.
  • Treatment switching is inferred from prescription records, not confirmed clinical decisions.
  • Over-the-counter glucose-lowering products are not captured in EHR medication tables.
  • Exposure definitions should be replicated when applying this pipeline to real-world claims/EHR data with NDC/RxNorm mapping.
